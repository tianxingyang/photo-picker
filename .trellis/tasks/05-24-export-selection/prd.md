# 导出精选

> Parent: `05-24-milestone-1-mvp`｜覆盖 ROADMAP M1 功能 ⑩导出精选

## Goal

把 `status='keep'` 的原片**复制**（不移动、不修改源）到用户选择的目标目录，保留原文件名。这是选片闭环的最终产出。

## Scope

### In Scope

1. 前端：选目标目录 → `invoke('export_keep', { destDir })` → 显示结果（导出张数/冲突/失败）。
2. Rust command：查 `status='keep'` 的 `path` 列表，逐个复制到目标目录，保留原文件名。
3. 复制语义：只读源、只写目标；源文件零改动。
4. 文件名冲突处理：目标已存在同名时的策略（跳过 / 改名加序号 / 覆盖——见决策点）。
5. 结果汇总返回（成功数、跳过数、失败项及原因）。

### Out of Scope

- 导出目录结构定制 / 按组分文件夹（M2+）；M1 只平铺复制保留原名。
- 元数据改写、格式转换、压缩；M1 原样复制字节。
- 导出进度可视化事件（M2）；M1 可一次性返回结果。

## 决策点

- 文件名冲突策略：跳过 / `name (1).jpg` 改名 / 覆盖。建议默认"改名加序号"，避免静默覆盖用户已有文件。
- 不同源目录下同名文件落到同一目标目录时的去重（同上冲突策略覆盖）。

## 软依赖

近乎独立。只读 `photos` 中 `status='keep'` 行；keep 状态由 keep-reject-status 写入，但本任务可用手工置几行 `status='keep'` 的种子数据独立验证。

## Acceptance Criteria

- [ ] 选目标目录后，仅 `status='keep'` 的原片被复制过去，文件名保留。
- [ ] 源文件未被移动、未被修改（字节级一致，mtime/内容不变）。
- [ ] 目标目录同名冲突按既定策略处理，不静默丢文件。
- [ ] 复制失败（权限/磁盘满）单项报错并计入汇总，不中断整体导出。
- [ ] 导出 0 张（无 keep）时给出明确提示，不报错。
- [ ] 三层 formatter 通过。
